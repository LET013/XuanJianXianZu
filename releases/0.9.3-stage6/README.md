# 0.9.3-stage6 发布前语义收口

本目录归档《玄鉴仙族》0.9.3 年度逻辑重构的发布候选结果。该分支基于 0.9.3-stage5 完成语义收口，**不覆盖仓库主线当前的 0.9.6 版本**。

## 已收口内容

- 功法、神通、求金法的机会债务不再跨前置条件继承；
- 新阶段从真实取得资格后的下一年起算；
- 武艺、四艺、法宝锻造与十年赐予进入精确年度车道；
- 次级年度补算使用对应逻辑年份的年龄、境界和技艺资格；
- 存读档、旧档迁移、手动升降境与遗失法宝年份边界完成收口；
- 同年世界快照绑定角色推进版本；
- 长局生态守卫跨存档持久化；
- 正式配置默认关闭阶段 0/5 诊断。

## 完整源码差异

`patch/part-*.patch` 是从 0.9.3-stage5 到 0.9.3-stage6 的完整 UTF-8 文本差异，没有省略任何源码、配置、测试或报告变更。

重建统一补丁：

```bash
cat patch/part-*.patch > stage5-to-stage6.patch
```

在 0.9.3-stage5 根目录应用：

```bash
git apply --check stage5-to-stage6.patch
git apply stage5-to-stage6.patch
```

统一补丁 SHA-256：

```text
9126ae049c11ec0c4420f4d60a1a5fabbaf8afd3c8df3d51fcf97a232dbcd3b0
```
